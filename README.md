# CrnaRupa
3D model of a black hole made in Blender

## Kako pokrenuti
Klonirajte git repozitorij i otvorite .blend datoteku i pritoskom tipje F12 se renderira jedan frame
Pritiskom tipke Shift + F12 renderira se cijela animacija koja će potrajati.
Prije rendera u postavke render outputa postavite valjanu export putanju datoteke da ne bi došlo do pogreške

video je dostupan na platformi youtube na linku https://youtu.be/VOWv3d9-U8Q
